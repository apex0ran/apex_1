# Project Statement

## Project name

Student Expense Tracker

## Problem

Students spend money every day on food, travel, books, mobile recharge, and other things.
 Small expenses are easy to forget. Because of this, students may not know how much money they spend in a month.

## Solution

This project is a simple Python program that runs in the terminal. It allows a student to add expenses and save them in a file. The student can later view, search, edit, delete, and get a summary of the expenses.

## Scope of the project

The project is made for one user and stores data only on the same computer. It does not need an internet connection, login system, or database server. Expense data is saved in a JSON file.

## Target users

College students who want a simple way to track their personal expenses.

## Main features

- Add an expense with amount, category, date, and note.
- View saved expenses.
- Search expenses by category or date.
- Edit or delete an expense using its ID.
- View total spending, category-wise spending, and month-wise spending.
- Save data in a local JSON file.

## Limits of the project

- It is a command-line application, not a mobile or web application.
- It stores data for only one user.
- It does not create a budget limit or send notifications.
